# Antigravity Live Browser ⚡

Инфраструктура интерактивной автоматизации браузера в реальном времени для **Google Antigravity** с **нулевой потерей интеллекта** (Zero Intelligence Loss).

Решает проблему изоляции рабочего стола (`exebox-...` Windows Station sandbox) и ликвидирует фоновый троттлинг Chromium.

---

## 🚀 Почему обычная автоматизация тормозит (и как мы это решили)

1. **Фоновый троттлинг таймеров (1 Hz Throttling):**
   * *Проблема:* Как только окно браузера теряет фокус или перекрывается средой разработки, Chromium замедляет выполнение `setTimeout` и промисов до **1 раза в секунду**!
   * *Решение:* Запуск с флагами `--disable-background-timer-throttling`, `--disable-backgrounding-occluded-windows`, `--disable-renderer-backgrounding` и отключением `CalculateNativeWinOcclusion`. Скрипты исполняются с миллисекундной точностью в любом состоянии окна.

2. **Отказ от искусственных пауз (`sleep` / `wait`):**
   * *Проблема:* Скрипты тратят 1–3 секунды на ожидание отрисовки кнопок.
   * *Решение:* Встроенный `dom_observer_hook.js` на базе `MutationObserver` возвращает управление в ту же миллисекунду, когда элемент появился в DOM.

3. **Аппаратное GPU-ускорение:**
   * Растрирование и композитинг отдаются дискретной видеокарте NVIDIA (`--enable-gpu-rasterization`, `--enable-zero-copy`), освобождая процессор для работы модели и агента.

---

## 📦 Файлы проекта

* `start_browser.bat` — скрипт запуска Chromium с флагами ультра-производительности на порту `9222`.
* `setup_scheduler_task.bat` — регистратор интерактивной задачи `AgentChromium` в Планировщике Windows с поддержкой работы от батареи и повышенным приоритетом.
* `dom_observer_hook.js` — модуль реактивного ожидания элементов без задержек.
* `AGENTS_RULE.md` — готовые системные инструкции для интеграции в правила агента.

---

## 🛠️ Установка и использование

1. Запустите от имени администратора:
   ```cmd
   setup_scheduler_task.bat
   ```
2. Для запуска браузера из агента:
   ```cmd
   schtasks /run /tn "AgentChromium"
   ```
3. Подключение и управление через CDP:
   ```cmd
   agent-browser --cdp 9222 open "https://example.com"
   ```
